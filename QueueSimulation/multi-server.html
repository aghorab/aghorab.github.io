Able and Baker: a two-server call center

Two technical support staff answer calls. Able is more experienced and faster; Baker is newer and slower. If both are idle, Able takes the call (unless the Baker-first rule is on); otherwise the call goes to whichever server is free first. If both are busy, the call waits in a single first-in, first-out queue.

Input distributions: probabilities, cumulative probabilities and random-digit assignments

When both servers are idle, Able takes the call (textbook rule). Turn the Baker-first rule on to send such calls to Baker instead.
