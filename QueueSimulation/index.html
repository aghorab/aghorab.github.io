Queueing Simulation

Modeling and Simulation, Chapter 3

A queueing system is a system in which customers arrive, wait in a line when every server is busy, receive service, and leave. Simulating it by hand with random digits and a simulation table shows how waiting times and server utilization arise from random arrivals and random service times.
