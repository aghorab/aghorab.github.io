Method, notation and sources

The simulation-table method

A queueing system is simulated by hand by filling a table with one row per customer. For each customer, random digits determine the time since the previous arrival and the service time. The remaining columns follow from simple rules: a customer begins service when the customer has arrived and the server is free, waits for the difference between the two times, and leaves when the service time has elapsed. The system starts empty and idle, and customer 1 arrives at time 0.

The totals of the columns give the performance measures, such as the average waiting time, the probability that a customer waits, and the proportion of time the server is busy. One short run is only one sample of a random process, so the measures change from run to run. Repeating the run many times (replications) shows how much they vary and gives a more reliable average.

Random-digit assignment

Each possible time receives a range of random digits whose size is proportional to its probability. The ranges follow from the cumulative probabilities. For example, a service time of 3 minutes with probability 0.30 and cumulative probability 0.60 receives the two-digit random numbers 31 to 60. A random number of all zeros (00 or 000) stands for the top of the last range (100 or 1000).

On this website, random digits come from a seeded generator, so that the same seed always reproduces exactly the same digits and therefore the same simulation table. A class can share a seed to work on the same run.

Notation

SymbolMeaning
A(i)Time between the arrival of customer i - 1 and customer i
S(i)Service time of customer i
Arrival(i)Arrival(i - 1) + A(i), with Arrival(1) = 0
Begin(i)max(Arrival(i), End(i - 1)): time service begins
Wait(i)Begin(i) - Arrival(i): waiting time in the queue (called delay in the call center)
End(i)Begin(i) + S(i): time service ends
System(i)End(i) - Arrival(i): time the customer spends in the system
Idle(i)Begin(i) - End(i - 1): idle time of the server before customer i
E(A), E(S)Expected time between arrivals and expected service time: the sum of each value times its probability

In the call center, the server chosen is Able when both servers are idle (textbook rule); otherwise it is the server that becomes free first, and Begin(i) uses the time that server is available.

Glossary

Interarrival time
The time between two consecutive arrivals (time between arrivals, or time between calls).
Service time
The time a server needs to serve one customer.
Utilization
The proportion of the run during which a server is busy: total service time of that server divided by the length of the run.
FIFO
First in, first out: customers are served in the order in which they arrive.
Replication
One independent repetition of the whole simulation with new random digits, such as one day of the Grocery Checkout or one run of the call center.
Seed
The starting value of the random-number generator. The same seed reproduces the same random digits and therefore the same results.
